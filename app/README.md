# Origin // ASO Sentinel dashboard

A React + Vite dashboard for the Origin contracts, running against a **local anvil chain only**.

```bash
npm ci
npm run local     # anvil :8545 → forge script DeployOrigin → bootstrap to FRESH → snapshot → vite :5173
npm run lint      # oxlint
npm test          # vitest (presentation-side risk helpers)
npm run build     # type-check + production build
```

- Transactions are signed with anvil's **public** test keys and are sent only to chain id 31337. There is no
  wallet. The app shows explicit states for loading, no deployment, chain unreachable and wrong network.
- Scenario logic is shared with the CLI demo: `../shared/origin-core.mjs`, with contract ABIs in
  `../shared/abis.json`, regenerated by `node ../shared/gen-abis.mjs`.
- `npm run local` writes `public/deployment.local.json` (gitignored). It holds disposable local addresses and
  the snapshot id that the **Reset chain** button reverts to.
- The Evidence view reads the committed Sepolia files in `../deployments/`. Those cover the v1 core only.
- The Validation view reads the committed result files in `../validation/` (baseline, rejected candidate, final;
  main and holdout suites), generated by `cd ../demo && npm run validate`. It can also re-run any case live on the
  local chain and compare it with the committed result.

See the root README and `docs/ORIGIN.md` for what each number means and what is enforced on-chain.
